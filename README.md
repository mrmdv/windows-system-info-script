# Скрипт для визначення характеристик комп'ютера на Windows 11

Цей репозиторій містить скрипти для повного отримання інформації про характеристики вашого комп'ютера/ноутбука на операційній системі Windows 11.

## 📋 Що визначається:

✅ **Назва комп'ютера** - ім'я в мережі  
✅ **Процесор (CPU)** - назва, кількість ядер, логічні процесори, тактова частота  
✅ **Жорсткий диск (HDD/SSD)** - загальний розмір, вільне місце, використано  
✅ **Клавіатура** - опис та статус  
✅ **Миша (маніпулятор)** - опис та статус  
✅ **Монітор** - опис та розширення екрану  
✅ **Дата інсталяції ОС** - точна дата встановлення Windows 11  

## 🚀 Як користуватися:

### Способ 1: Запуск батника (найпростіший)

1. **Завантажте файли репозиторію**
2. **Клікніть правою кнопкою** на файл `run-system-info.bat`
3. **Виберіть** "Запустити від імені адміністратора"
4. **Дочекайтеся** завершення скрипту

### Способ 2: Запуск PowerShell скрипту вручну

1. **Відкрийте PowerShell** від імені адміністратора
2. **Перейдіть** до папки зі скриптом:
   ```powershell
   cd "C:\шлях\до\папки"
   ```
3. **Запустіть** скрипт:
   ```powershell
   .\get-system-info.ps1
   ```

### Способ 3: Через командний рядок (CMD)

```cmd
powershell -NoProfile -ExecutionPolicy Bypass -File "get-system-info.ps1"
```

## ⚠️ Важливо:

- ✋ **Скрипт потребує прав адміністратора** для коректної роботи
- 🔒 Якщо виникає помилка про політику виконання скриптів, див. розділ нижче

## 🔧 Розв'язання проблем:

### Помилка: "Виконання скриптів заборонено в цій системі"

Відкрийте PowerShell від імені адміністратора та виконайте:

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

Потім погодьтеся на запит, натиснувши `Y` та `Enter`.

### Вихід команди не відображається

Переконайтеся, що ви запустили скрипт від імені адміністратора.
